# ÉLANE Spa & Wellness — Website Concept

A responsive, single-page spa website concept created for a client presentation.

## Preview
Deploy this repository with Vercel. The site is a static HTML/CSS/JavaScript website; no build command or environment variables are required.

## Included
- Responsive desktop and mobile layout
- Treatment and package showcase
- Appointment enquiry modal (front-end demonstration only)
- Contact and location placeholders
- Demo pricing and clearly labelled sample testimonials

## Before production launch
Replace the fictional brand, prices, contact details, address, opening hours, images and sample reviews with client-approved content. Connect the enquiry form to a real booking, email or WhatsApp workflow. Add the client's domain and analytics after approval.

## Local preview
Open `index.html` in a browser.
